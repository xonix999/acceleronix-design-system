Solid color circle holding a white pictogram, used above pillar-card headlines.

```jsx
<IconCircle color="var(--purple)"><img src="https://unpkg.com/lucide-static@latest/icons/globe.svg" style={{width:22,height:22,filter:'invert(1)'}} /></IconCircle>
```

Pictograms are substituted from Lucide (CDN) — no usable pictogram set could be extracted from the source material. See ICONOGRAPHY in the root readme.
